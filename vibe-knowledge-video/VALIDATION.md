## 复现主要检查

在完整包根目录执行：

```sh
python -m pip install -r skills/vibe-knowledge-video/requirements.txt
python -m unittest discover -s tests -v
```

在 `skills/vibe-knowledge-video/assets/starter` 执行：

```sh
npm ci
npm run setup
npm run check
npm run test:setup
npm run render -- --scale=0.5 --frames=390-509 --concurrency=1 --image-format=png
```

`setup` 已存在配置时会拒绝覆盖；需要换音轨或静音时按实验说明使用明确选项。渲染生成独立目录，检查真实输出时传入本次的 960×540、60 fps、2 秒等预期值。窗口、设备与音轨变化后，按实际需求补做观看和试听。

本地临时报告保存在 `.validation/`，不进入分发包；包内提供可重做检查的脚本和测试。GitHub CI 的执行结果应以对应提交的实际检查状态为准，未执行的远端检查不在此记为通过。
