# 可选实验 BGM 与自定义音乐

本文件夹包含本次案例实际使用的原始音轨 `reference-bgm.m4a`。它来自用户提供的 [B 站参考视频](https://www.bilibili.com/video/BV1mLWw6VEux/)，并按用户要求随包保留；音乐的独立许可尚未确认，不属于原创代码的 MIT 许可。可换成自己有权使用的音轨。

本素材保留用于原 12 秒技术实验。每条新视频先确认声音方案，可以不用音乐、使用旁白或选其他配乐；本素材不构成新视频的默认选曲或风格。

## 实验素材

- 解码长度：181.951565 秒；原始 AAC、44.1 kHz、双声道。
- 本次旧工程的节拍拟合约 **111.62 BPM**，仅作选曲与编排参考；拍号和小节第一拍未确认。
- 原始素材的散列与案例测量保存在 `profile.json`。这些记录不是通用卡点表，也不是新工具的精度承诺。
- 案例最终配乐从原素材约 **4.479206 秒**处开始剪取。成片里的 12.733、69.433、98.733 等时刻属于**剪辑后的音轨**，不能直接套在这里的原文件上。
- 第一遍可以直接用本素材完成节奏实验；实际新片要对最终裁剪、拼接后的音轨重新分析并试听。

## 换音乐

1. 将自己的 WAV / MP3 / M4A / 带音轨 MP4 放入新视频的 `assets/music/`。
2. 用 `scripts/analyze_bgm.py` 分析新文件，输出到该视频的 `qa/`。具体命令见 [工具手册](../../references/tools.md)。
3. 记录原文件 hash、剪辑区间、循环段、淡入淡出与增益。分析最终播放的版本；重新选择章节边界和揭晓瞬态。
4. 把音乐导入 `film/public/audio/` 并更新配置，按 starter README 的命令操作。导入只换声音，不会自动重写镜头、字幕和事件时刻。
5. 复核 15 秒开场、最复杂机制与所有主揭晓。不要只改文件名后沿用原 BPM 或所有旧 cue。

如果内容长于音乐，可在相同乐句或和声位置循环、交叉淡化，再重新分析；不要为了迁就音乐，把必要解释删掉，或无说明地把整首歌加速。
