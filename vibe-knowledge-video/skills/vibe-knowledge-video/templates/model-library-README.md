# 本项目的三维模型库

模型文件保存在本目录的独立子目录中，`inventory.json` 初始为空数组，表示尚未登记模型。它不是随 skill 赠送的模型包，也不表示磁盘上一定没有未登记文件。

## 新任务怎么查

制作新片、定视觉方案或新增／替换素材时，先读本文件和索引，再核对实际文件。已安装 skill 时，可在项目根目录运行：

```sh
python .agents/skills/vibe-knowledge-video/scripts/scan_models.py --project .
```

盘点只检查文件和部分结构；画质、科学身份、可动部件与许可仍应结合来源、实际导入和试渲染确认。选择结果写进 `planning/asset-plan.md`。已有自定义目录或索引时保留其约定，不为套用模板移动原文件。

## 登记建议

- 每个模型独立存放原文件及 `source.json`；记录作者、作品页、许可／署名、下载或转换方式、文件大小和已知限制。
- `inventory.json` 使用条目数组；每项至少有 `id`、`title`、`path`。`path` 相对于本 `assets/models/` 目录，例如 `dna/dna.glb`。可补充 `sourceRecord`、`sourceUrl`、`license`、`usability`、`limitations` 和已实际完成的预览路径。
- 不把缺失文件、下载中的文件或仅有来源链接的条目记成可用模型。索引可保存待补齐条目，但应明确状态。
- 保留下载原件，在镜头中调材质、灯光、缩放和运动；衍生文件另存并记录修改。新增／替换后更新索引和项目状态。

两套模型可能都叫“细胞膜”，却分别是造型示意和实验坐标转换。选用时看本片需要解释的内容，不凭文件名或颜色认定科学结构。
