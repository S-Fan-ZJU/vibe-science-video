# 修订任务

```text
当前正式版本／文件：[填写]
时间范围：[例如01:07.0–01:08.2]
对象：[模型、文字、音乐、音效、转场等]
实际现象：[描述看见或听见的现象，不先猜原因]
目标变化：[例如结果提前击中重拍、缩短空等、孔洞真正贯通]
必须保留：[满意镜头、原时间轴、已有音乐、标题等]
交付：[先局部对比／直接完整修正版]
```

制作方填写：

| 项目 | 记录 |
|---|---|
| 问题证据 | 原文件、帧号、截图或片段 |
| 已确认原因 | 没确认时写“未确定” |
| 选择的修复范围 | 换音轨／局部补渲／重排或重渲全片／发布素材 |
| 受影响的文件 |  |
| 新版本与旧版本位置 |  |
| 复核范围 | 受影响片段、边界、文件完整性、声音与字幕 |
| 实际结果 |  |
| 仍待检查的部分 |  |

“更有冲击力”可落实为：主动作结果更早、更明确；准备和释放有反差；构图靠近关键对象；文字强调更短；关键声音在音乐中可听。选择符合问题的一项或几项，不必同时加满所有效果。
