# 把参考片拆成可迁移的方法

用于用户提供参考视频、希望学习某类视觉／节奏，或为新题材选择表达方式。先完成 [用途与风格确认](style-and-purpose.md)，再选有关的片段。原科研成片与动感参考属于不同的可选方向，不能用某一批参考统一所有知识视频的审美。

## 1. 一段参考至少记录六项

| 项目 | 应记录的内容 |
|---|---|
| 身份 | 原链接、作者／片名、本地文件与 SHA-256、分辨率／fps／时长；版本不同应重定位时间 |
| 检查覆盖 | 全片间隔采样、局部密集采样、连续播放、主观试听、事实核验分别完成到哪里 |
| 可见证据 | 精确到采样范围的对象、位置、状态、文字、颜色和运动；注明真实选帧时间 |
| 解释功能 | 这段帮助观众理解哪种因果、比较、数量、空间、时间或观点关系 |
| 迁移决定 | 采用什么、解决本片什么问题、不采用什么；画面方法和知识事实分开 |
| 验证方法 | 目标结果帧、对象连续性、读图顺序、手机可读性及最终播放的检查方式 |

先用间隔抽帧理解全片结构，再对关键动作加密采样。半秒间隔适合看状态顺序，不足以证明首个结果帧或精确卡点。可以用 [抽帧工具](tools.md#参考视频的时间码抽帧)保存图片、拼图和真实时间；检查工具输出与画面，而不是把它当作自动审美结论。

只有链接而未取得视频时，记录访问状态及可观察范围。不要假装已经观看。视频可正常取得时保留来源；遇到登录或下载限制，使用正常可访问版本或用户提供的文件，不绕过限制。仅供学习的素材不自动获得再分发或成片使用许可。

采用这些方法时，新分镜至少写出“追踪对象、可见变化、结果时点、下一镜头承接”。可给跨场景对象稳定 ID，让颜色、锚点、路径历史和组别关系延续；一场换皮肤不应让观众误以为出现新对象。

## 3. 颜色和音乐响应是可配置的层

颜色先承担辨识任务：同一对象身份稳定，背景不竞争，状态和类别不混用。鲜明感可以来自明度、冷暖或轮廓分离，不必全局提高饱和度。科研方向也可使用鲜明色彩；是否发光、闪烁和震动要服从本片确认。

选择音乐联动时分成三层：

| 层 | 输入 | 可选响应 |
|---|---|---|
| 持续起伏 | 最终音乐的平滑能量与段落强度 | 局部光晕、轮廓、少量粒子的缓慢变化 |
| 普通拍点 | 复核过的起音／重拍候选 | 线条短亮、轻微缩放、局部粒子脉冲 |
| 关键揭晓 | 人工安排的内容事件与声音攻击点 | 在结果帧提高动作、颜色或文字强调，迅速回到可读状态 |

每层可单独调弱或关闭；正文不需要跟拍闪动。音乐亮度与内容机制状态分别控制，避免把随拍点起伏看成装置反复开关。每个响应记录对象、峰值、消退时间和最大幅度，由帧号、fps 和预计算数据决定。

局部观察例：《37%法则》25.600、28.233 秒出现较短的亮度／彩边脉冲，29.300 秒出现更强金色揭晓；成片混音瞬态候选约为 25.583、28.233、29.303 秒。这只支持这些局部变化在视频帧尺度附近对齐：视频 30 fps（约 33.3 ms／帧），音频分析步长约 10 ms、窗口约 46 ms，且未分离 BGM／SFX、未主观试听，不能宣称毫秒级精度或全片卡点都准确。

亮度跳变也可能来自新文字、物体旋转和换景。必须看前后帧并听对应声音，不能把检测到的所有亮度峰和声音起音都标成音乐闪烁。

## 4. 从分析到实现，保持能力边界

这些经验已支持过一条 15 秒《希特勒的溃败》动感样片：路线推进借鉴《四渡赤水》，分级光效借鉴《37%法则》；能量起伏、普通瞬态和主事件响应已实际实现，4K60 与 1080p60 已通过完整解码等文件检查。它仍待用户评价，使用参考成片混音做风格试验，不能因此认定音乐可公开复用或强度已获认可。

该样片中的音乐选段、900 帧／60 fps、四个主 cue 和欧洲地理仍与单片绑定；本包没有将它包装成“换文案即可适用所有题材”的组件。整体／局部窗、通用网络、样本筛选、曲线与结果矩阵是可用的设计方向，需要按任务实现和验证，不宣称本包已经全部提供。

从单片中抽取通用能力时，将数据、主题、版式、时间和素材分开。优先拿一个具体解释任务验证接口，例如“序列出现→基准建立→越线→结果稳定”，再决定是否扩大组件库。图表数值来自核验数据；需要模拟时保存假设、种子、样本量和输出，动画计数不等于真实计算证据。
