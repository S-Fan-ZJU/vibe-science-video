# 把知识变成观众愿意追下去的故事

用于新选题、资料解读、开场改写、字幕节奏修改。先按 [用途与风格](style-and-purpose.md) 确认本片任务，再建立知识关系和声画。配套使用 [brief](../templates/brief.md)、[事实表](../templates/fact-ledger.md) 和 [分镜表](../templates/storyboard.md)。科学机制、历史事件、数学规则和人文观点可以采用不同叙事，共同要求是事实与解释依据清楚。

## 1. 明确这条视频的解释承诺

用一句话回答：“谁为什么会关心这个问题，看完后能解释什么？”

较弱：介绍合成生物学的应用。

较强：药物怎样利用身体里的信号，在合适的地方启动作用？用几个工程化细菌研究策略，看懂感知、计算、输出和控制之间的关系。

范围太大时，选一条能讲清的主线：因果、时序、规则推导、条件比较或观点与证据的关系。支持 2–4 分钟及更长时长，但新增每一段都应增加理解。资料很多不等于需要全部出镜，也不能把所有历史进程或文本解读强行画成单一因果链。

先写四项：

| 项目 | 要写出的内容 |
|---|---|
| 观众已有直觉 | 例如“细菌通常意味着感染” |
| 想改变的理解 | 活细胞可被设计为响应信号的系统，但工程控制并不容易 |
| 可视化的核心过程 | 输入条件 → 状态改变 → 输出行为 → 反馈或限制 |
| 不能偷带的结论 | 研究策略不自动等于可普遍使用的治疗；不同方案不等于同一菌株全具备 |

## 2. 从来源到事实表

优先读用户提供的完整资料。先判断文件是原始记录、研究、综述、新闻、教学材料、文学／神话文本还是观点文章。不要把综述示意图当作单项实验的实际结果，也不要把参考视频或网络转述当作已核验的原始出处。

不同题材重点核对不同的边界：

| 题材 | 核对重点 | 易被动画误导的地方 |
|---|---|---|
| 科研与技术 | 对象、实验条件、证据层级、研究策略、结构与输入输出 | 把示意模型当实测影像，或把不同方案拼成一个全能系统 |
| 历史与地理 | 事件日期与先后、史料出处、人物身份、地图年代、路线与数量 | 把事件先后当唯一因果，把推进方向示意当精确战线／疆界 |
| 神话、文学与人文 | 文本版本、传统与语境、引文归属、原文与阐释的区别 | 将某一版本写成唯一传统，将改编情节或个人解读当史实／共识 |
| 数学与概率 | 定义、假设、优化目标、有限与极限情形、推导与数值 | 将一个目标的最优解套到另一个目标，或把动画计数当模拟证据 |
| 心理、社会与经济 | 样本、测量、对照、时间范围、相关与因果、适用人群 | 将平均结果推广到所有人，把描述性结果变成普遍建议 |

涉及计算时，保存公式或程序、输入、单位和可复现输出；涉及模拟时再保存种子、样本量与假设。涉及历史争议或文本阐释时，把有依据的不同解释标清，不用戏剧化动作消除真实的不确定性。所有风格使用同样的事实标准。

事实表的每一行至少包含：结论、对象和条件、出处定位、视觉表达、简化或比喻、禁止暗示。涉及数量和结果时补单位、对照、时间范围、样本／模型。文献中的“可”“可能”“在某条件下”不能在字幕中无意变成无条件的“会”。

处理科学范围时优先改变主语和动词：

- “一种设计让两类输入共同控制生长”比“细菌能准确识别所有肿瘤”更具体。
- “研究者在这个模型中观察到……”可以保留必要证据层级，不必每个镜头都插入整屏免责声明。
- 动画比喻第一次出现时用简短标注或准确措辞说明；片尾或简介提供主要来源。

若一个限制决定结论是否成立，它必须留在对应正文附近。来源页不能修复正文中已经造成的错误印象。

## 3. 让解释有动作

把抽象句转成“条件变化 → 对象行为 → 可见结果”：

| 抽象句 | 可观察的叙事 |
|---|---|
| 两个输入共同决定输出 | A 单独到来没有输出；B 单独到来也没有；两者同时存在才改变状态 |
| 信号积累到阈值 | 少量对象释放弱信号；数量增加使周围信号变密；跨过阈值后改变行为 |
| 抑制被解除 | 先显示抑制联系如何阻碍行动，再让分子阻断联系，最后行动得以发生 |
| 形成反馈 | 输出改变环境；环境变化反过来影响下一轮输入或输出 |

关键是比较。只有成功画面，观众可能只记住炫酷开门；加入一个清楚的失败或对照，才看懂“为什么要两个条件”。对照无需很长，但变量应明确。

不要让机制主体只是漂浮背景，而让字幕承担全部解释。静音看一遍动作，应该能看出谁影响谁；遮住画面读字幕，逻辑也应该成立。两者结合提供更完整的理解。

## 4. 按用途写开场

优先选择和主题本身有关的视觉动作。科研／教学可直接提出研究问题或比较任务；大众与娱乐传播可从处境、冲突或反直觉进入。下表是可用结构，不要求每片都制造强悬念：

| 阶段 | 观众任务 | 画面任务 |
|---|---|---|
| 立刻建立对象 | 我在看什么 | 一件可辨认物体＋明确动作，避免先等长片头 |
| 制造值得解释的矛盾 | 为什么会这样 | 让直觉预测和实际结果出现差异 |
| 提出片中会兑现的问题 | 接下来要解决什么 | 用动作收束、构图聚焦或短暂停顿留出问题 |
| 揭晓主题 | 这条视频讲什么 | 主体状态变化、片名和音乐一起出现 |

可选开场方向：

- **人的处境**：想解决一个现实问题，但现有办法带来代价或取舍。
- **反直觉实验**：相同动作出现意料之外的结果，再问背后的机制。
- **尺度反转**：从熟悉物体推近，发现里面正在发生的过程。
- **选择困境**：给两个看似合理的选项，用可视化揭示为什么都不完整。
- **证据或时间问题**：从一份史料、一张图表、一个物件或两个有差异的记录开始，说明本片如何解释它们。

医学题材里，不用夸张受伤镜头、绝望话术或否定有效治疗来制造悬念。人文关切可以来自“更少代价、更精准、更可控”的具体目标。

### 本案例的开场结构

先看到手术刀实际切除病灶，再看到药物作用与身体负担，提出“药，能不能自己判断？”，最后揭晓工程化细菌。它有吸引力的依据是对象、动作、问题和答案相连。不能把相同医疗开场直接套到物理、数学或气候主题。

开场评审问五件事：

1. 第一秒已经能识别主要对象吗？
2. 字幕说到的动词真的发生了吗？
3. 前几秒是否出现了值得解释的矛盾？
4. 片名出现前，观众知道为什么关心吗？
5. 即使去掉大标题，画面是否仍有清楚含义？

## 5. 问题链与有内容价值的爆点

好的问题来自刚学会的知识尚未解决的部分。例如：找到环境 → 单信号会误判吗 → 谁决定何时释放 → 释放物如何作用 → 外部能否控制 → 控制还难在哪里。

每段用三句话起草：

> 问：观众此刻自然会问什么？
> 答：这一段给出的准确答案是什么？
> 证：哪一个动作、对照或图形让这个答案可见？

只有问句没有“证”，先修分镜；没有新答案，合并段落。把下一问放在上一答清楚之后，避免每十秒吊一次胃口却不兑现。

每个主要揭晓定义一个**结果事件**：锁第一次打开；载荷第一次跨出膜；抑制连接第一次断开；生产指示第一次保持点亮。它是内容上的变化，不只是屏幕闪白。

按本片风格安排强度：普通解释保持可读，主要转折可以扩大主体或声画反差，也可以仅用克制的标签和状态变化强调。选择动感方向时再安排蓄势与释放；不规定每隔固定秒数必须爆一次。结果应先可见，再给结论或评价。

## 6. 字幕停留：区分阅读任务和观察任务

“字幕太久”可能指四种不同问题：

| 现象 | 应优先修改 |
|---|---|
| 字已经读完，图也不变 | 缩短停留，推进下一信息 |
| 字迟迟没有全部出现 | 缩短入场，让完整语义尽早可读 |
| 观众读字时错过关键动作 | 让动作稍后兑现，或拆成先读／后看两个阶段 |
| 文字术语密、读不懂 | 改写句子和解释顺序，必要时延长观察 |

每条字幕记录：入场区间、稳定可读区间、观察任务、离场时刻。字速只是诊断指标，不能代替观看。中文复杂术语、英文缩写、数值、图表都需要额外处理。

正文常用一至两行，保持视觉重心稳定；关键词可以短促强调，整句不必逐字猛烈弹跳。短句出现完整意思后，留一段相对静止的阅读时间。不要让文字入场和离场占掉大部分可读窗口。

本案例最终 43 条字幕，单条约 3.07–5.38 秒，最高约 5.70 中文字／秒；这是已完成案例的统计，并非本 skill 的阈值。新主题可更快或更慢，按真实阅读任务判断。

## 7. 结尾回到主问题

结尾先收束已兑现的理解，再提出真正还未解决的问题。好的余味来自“理解之后的新问题”，不是突然跳出一个与正文无关的宏大口号。

例如已经解释感知、计算、输出，可以问“能启动之后，怎样做到可靠地停止？”这比直接宣告“未来已来”更有深度。来源、视觉比喻说明和必要范围可以集中在结尾及简介，但不要把整段结尾塞成小字墙。

脚本完成后从头只读每段的“结论”和“转场理由”。如果逻辑仍然连贯，再进入细化镜头；否则先修叙事，而不是让更亮的粒子掩盖跳跃。
