# 让画面达到发布标准

用于设计画风、选择资产、制作三维机制、改进动效与转场。目标是具体、可追踪的空间关系和有分寸的冲击，不是尽可能多的发光粒子。

## 1. 先建立一张视觉规则表

开工前为主对象定义颜色、轮廓、材质、运动习惯和语义。配色至少在同一条视频中稳定；下一条可以换风格。案例里的青绿细菌、金色载荷、蓝色信号、玫红目标只是一个方案。

| 层级 | 职责 | 失败征兆 |
|---|---|---|
| 核心主体 | 观众始终知道在追踪谁 | 主体和背景同亮，或每镜换外形导致失认 |
| 机制层 | 显示输入、连接、接触、阈值和结果 | 只有漂浮装饰，没有行为关系 |
| 环境层 | 用尺度、遮挡、暗部和光线建立空间 | 背景比主体抢眼，微粒穿过文字 |
| 文字层 | 命名、提问、强调、总结 | 同屏多块标签竞争，字幕盖住动作 |

先挑一个代表镜头，做到最终材质、灯光和文字标准。再把规则推广到其他场景。只有开头精致、中段仍是占位几何，不能视为完成风格验证。

## 2. 按解释需求选择技术

在新建模型或下载素材前，按 [模型库复用流程](model-library.md) 检查本地候选。选用依据是本片需要解释的结构与动作；现有素材的配色和展示方式可以调整，原件与来源保持可追溯。

| 任务 | 推荐起点 | 不宜依赖的方式 |
|---|---|---|
| 数量变化、阈值、图表、逻辑比较 | 2D／SVG／Canvas／精确排版 | 随意漂浮的 3D 物体替代数据 |
| 插入、旋转、开合、包裹、遮挡 | 可按帧控制的 3D 或可验证的分层动画 | 单张图的放大缩小假装完整机制 |
| 氛围背景、组织纹理、宣传封面 | 原创图像或来源明确的素材 | 无关图库照片拼贴 |
| 连续角色行为、因果转变 | 可编辑的动画主体 | 难以稳定复现且机制不准确的随机片段 |

2D 也可以有很高的完成度。不要把题材不需要的 3D 当成门槛。只有涉及真实空间关系时，三维建模的成本才通常带来解释收益。

## 3. 资产应在静止与运动中都成立

对一个主要资产做六项检查：

1. **轮廓**：缩小到手机观看尺寸仍能辨认对象。
2. **结构**：外壳、内部、连接处与出口有明确区别。
3. **材质**：粗糙度、透光、反射表现和对象一致；不是所有表面都像同一种玻璃。
4. **灯光**：主体有足够明暗分离，不靠全局提亮使背景一起灰掉。
5. **动作**：接近、接触、改变状态都有可以观察的阶段。
6. **性能**：最终渲染条件下能稳定输出，密集粒子和透明重叠不会导致不可接受的耗时或排序错误。

原始生成图分辨率低于最终输出时，记录素材原生尺寸；4K 输出画布不表示所有素材原生 4K。不要把 AI 图里看似精细但机制错误的结构作为不可改的事实。

## 4. 动效的重量来自阶段和反差

主动作可拆为：准备 → 接近 → 接触／约束 → 结果 → 余振／稳定。用这些阶段服务因果，而不是每个元素都同样弹性入场。

| 动作类型 | 可用的视觉线索 |
|---|---|
| 轻颗粒移动 | 小尺度位移、轻微拖尾、快速收束 |
| 重物或机构运动 | 短蓄势、清晰轴心、接触停顿、有限余振 |
| 释放 | 内部先积累、边界破开、载荷沿明确方向跨出 |
| 状态开启 | 指示或材质改变并保持，随后观察其后果 |
| 失败尝试 | 运动达到约束位置，输出保持不变，给出简短反馈 |

主揭晓可以短暂放大构图、灯光或文字；解释段回到稳定视角。镜头震动、色差、闪白与持续模糊很容易损害阅读，若使用，应短暂并有明确事件依据。

摄影机运动先回答“带观众看哪里”：推进到阈值、绕到遮挡后方、沿信号进入目标。没有解释任务的连续旋转会让观众丢失方向。

## 5. 三个可改造的机制镜头配方

### A. 双条件开锁

叙事顺序：A 到来 → 没开；B 单独到来 → 没开；A 与 B 同时满足 → 输出开启。视觉隐喻可用双钥匙、双接口或双光路，不限定锁。

若选择钥匙：孔洞必须真实贯通，不能用黑色圆片覆盖实心套筒；钥匙头、轴、齿和锁体应可区分。插入、旋转和开门各有轴线，检查齿尖在完整旋转过程中的扫掠体积。开门后保留结果，给观众看到“通过”而不只是闪了一下。

只做两个符号同时发光并不一定能解释 AND。失败与成功对照是理解的关键。

### B. 积累、阈值和释放

先显示内部载荷与外部信号的区别；数量或信号逐步增加；阈值达到前先完成准备；重拍到来时边界已经出现明确分离，载荷开始跨出。

不同策略可能有不同结局。若研究是周期性裂解与幸存者再生长，不要把所有个体都永久清零；若是单细胞分泌，不能擅自改成爆炸释放。

### C. 包裹与吞噬

先让观众识别吞噬者和目标，再显示接近和接触；包裹边缘沿目标周围推进，接缝最终闭合；目标进入内部后改变可见性。不要让目标突然缩没，也不要把辅助分子或细菌画成吞噬主体。

机制需要简化时，保留因果和角色关系，去掉非必要细节。让薄膜穿过目标再突然消失，会破坏解释可信度。

## 6. 三维与透明层的检查方法

区分几何相交与透明排序。两个对象世界坐标上相交，改 renderOrder 不能真正修复；几何没相交却出现前后反转，才查透明深度与分组排序。

- 使用物体完整边界而不是中心点判断间距。缩放、旋转、形变后重新计算世界空间范围。
- 检查移动全过程，包括过渡中间帧，不能只看起点和终点。
- 对钥匙、铰链等窄间隙结构，检查保守包围范围或采样顶点到障碍物的距离；记录覆盖范围，不夸大为连续碰撞证明。
- 共享材质如被一个对象调暗或改透明度，会影响其他复用对象；需要独立状态时克隆材质。
- 保留物体内部的膜、内核、载荷层次，再处理物体之间的前后关系。盲目把所有透明物体设置同一全局顺序常产生新问题。
- 需要稳定可复现的材质、灯光和相机状态，避免前一帧或资源加载时机改变下一帧。

QA 选帧至少覆盖入场、主动作前后、最大旋转、完全开启／闭合、离场。高风险接触要检查相邻帧或短片。

## 7. 转场设计：从前一场留下的东西出发

每次转场填写五项：

> 旧场景留下什么对象 → 镜头或对象怎样运动 → 哪里掩蔽场景交换 → 新场景承接什么 → 何时恢复可读构图。

| 转场 | 适用关系 | 要检查的断点 |
|---|---|---|
| 同形接续 | 一个圆、孔洞、膜面对应下一场同形主体 | 大小、位置、方向是否突跳 |
| 尺度推进 | 从器官进入细胞，从细胞进入内部结构 | 观众能否理解比例变化；是否需要短标签 |
| 跟随信号 | 一个因果作用从来源到目标 | 信号方向和目标身份是否持续一致 |
| 前景遮挡 | 表面或实体充满画面后换场 | 交换帧是否真的被覆盖；文字是否突然闪出 |
| 对照重排 | 同一对象从失败状态进入成功状态 | 保留参照物，避免像换了完全不同实验 |

不是每一场都需要很长转场。短的有方向的接续比无意义的大飞行更紧凑。转场中如果出现字幕，字幕的语义必须属于当时可见的画面。

## 8. 交给独立检查者的画面问题

把“好不好看”拆成可回答的问题：我第一眼看哪里？哪一个物体改变了状态？为什么改变？这个动作在声音响起时已经发生了吗？转场后我知道在什么尺度、看谁吗？有没有字已经读完但画面还没开始解释？

如果回答不清楚，优先改构图、动作和信息顺序，再增加装饰。视觉冲击应让关键关系更容易看见。
