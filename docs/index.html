装上就一定能一次做出同样的成片吗？+

不能保证每个题材零修改。这套 skill 把本次反复修订得到的关键决策、可运行起点和验收方法前置，减少本可避免的返工。选题、素材、设备和你的判断仍然影响最终结果。

可以改 BGM、时长、画幅，或者加旁白吗？+

可以。这些是可覆盖的默认值。换音乐需要重新分析最终音轨；改竖屏需要重排主体和字幕，不能只换封面；旁白版要按讲述节奏安排镜头。

包里的音乐和代码使用同一种许可吗？+

原创代码与文档使用 MIT。参考 BGM 来自用户提供的视频音轨，其独立许可未确认，不属于 MIT。仓库保留来源和替换入口，公开或商业使用请选用自己有权使用的音乐。完整来源说明 ↗
