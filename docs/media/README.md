# 展示素材

`showcase.mp4` 是《把细菌，变成药》最终作品的 **24 秒片段选编**，用于展示实际制作目标。它不是本仓库 12 秒通用动作实验模板的自动输出，也不是完整科普解释。

选编顺序：开场动作 → 片名揭晓 → 双钥匙逻辑门 → 群体感应释放 → 免疫机制 → 超声触发。保留来源成片声轨，剪辑边缘做 15 ms 淡入淡出。各段是非连续展示，不构成同一菌株同时拥有全部机制的科学论断。

展示版：1280×720、30 fps、H.264/AAC。来源成片为 177.466667 秒、4K60 母版及 1080p60 播放版；此处使用 1080p60 播放版缩小生成网页预览。完整源视频与论文 PDF 不随本仓库分发。

`poster.jpg` 为来源成片 14 秒画面的缩小预览。`showcase-edit.json` 保存片段范围与文件哈希。`make_showcase.py` 可在提供自己的来源成片后重建：

```sh
python make_showcase.py "path/to/living-medicines-v3-patched-1080p60.mp4"
```

需要 PyAV、NumPy、Pillow；现有输出不覆盖，明确需要更新时增加 `--force`。涉及参考 BGM 的授权范围见仓库第三方资源说明；音乐不属于本项目原创代码的 MIT 授权。
