这里存放网站「3 支全新原创样片」的网络播放版本及海报。它们围绕三个新问题独立制作，与上一节 24 秒的《把细菌，变成药》原作品节选分开展示。

| 样片 | 播放文件 / 海报 | 核心解释 | 展示能力 |
| --- | --- | --- | --- |
| 白光里，藏着多少颜色？ | `prism-reveal.mp4` / `prism-reveal.jpg` | 棱镜内不同波长的光传播方向不同，白光展开为光谱 | 玻璃材质、立体光路、光谱揭晓 |
| 用声音，让世界安静？ | `noise-cancellation.mp4` / `noise-cancellation.jpg` | 反相声压叠加可降低耳边的噪声 | 反直觉开场、声压波形、动态文字 |

交付目标为每段 18 秒，16:9，网页播放版本 1280×720、60 fps。海报与网页文件一一对应。可编辑工程位于 [examples/gallery](../../../examples/gallery)。

## 渲染与检查交接

- 三支样片的重要揭晓候选点为 8.4 秒，即 60 fps 下的帧 504。**这是分镜计划，不能直接当作已经核验的卡点结果。** 应对最终混音和成片逐帧确认。
- 发布前检查最终文件时长、分辨率、帧率和完整解码；确认三张海报均来自各自成片。
- 视频播放不自动开始。海报在接近可见区域时加载；用户启动新视频时暂停其他视频，避免多段声音叠加。
- 网页移动端应检查大标题、按钮和影片画面是否完整显示；用键盘确认播放、暂停、复制指令和折叠内容可操作。
- 科学表达检查：棱镜不能画成创造出颜色；降噪不能暗示所有地点或频率都完全安静；多米诺不能暗示能量来自无中生有的放大。

本文件记录预期交付与检查入口，不代替最终成片验收记录。
